# SeatSync — จองที่นั่งหอสมุด มมส. — คู่มือนำไปใช้งานจริง

โปรเจกต์นี้แปลงมาจากต้นแบบ (Artifact) ให้พร้อมสำหรับนำขึ้นเว็บจริง และรองรับการ
"เพิ่มลงหน้าจอโฮม" ในมือถือให้หน้าตาเหมือนแอป (PWA)

## วิธี deploy ขึ้นเว็บฟรีด้วย Vercel (ไม่ต้องเขียนโค้ดเพิ่ม)

1. สมัครบัญชีที่ https://vercel.com (ใช้ GitHub login ได้)
2. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo ใหม่ (หรือใช้คำสั่ง `vercel` จากเครื่องตัวเอง
   ก็ได้ ถ้าติดตั้ง Vercel CLI ไว้)
3. ในหน้า Vercel เลือก **Add New → Project** แล้วเชื่อมกับ repo ที่อัปโหลดไว้
4. Vercel จะตรวจจับว่าเป็นโปรเจกต์ Vite อัตโนมัติ ไม่ต้องตั้งค่าอะไรเพิ่ม
   กด **Deploy** ได้เลย
5. รอประมาณ 1 นาที จะได้ลิงก์เว็บ เช่น `https://msu-library-booking.vercel.app`
   เปิดจากมือถือหรือคอมพิวเตอร์ก็ได้ทันที

ทางเลือกอื่นที่ทำแบบเดียวกันได้: **Netlify** หรือ **GitHub Pages**

## ทำให้ "ค้นหาเจอบน Google"

เว็บที่ deploy แล้วจะยังไม่ขึ้น Google ทันที ต้องรอ Google เข้ามาเก็บข้อมูล
(อาจใช้เวลาหลายวันถึงหลายสัปดาห์) วิธีเร่งให้เจอเร็วขึ้น:

1. ไปที่ [Google Search Console](https://search.google.com/search-console)
2. เพิ่มโดเมนเว็บที่ได้จาก Vercel
3. ส่ง sitemap หรือกด "ขอ indexing" หน้าแรกของเว็บ

## ทำให้กดเพิ่มลงหน้าจอโฮมแล้วเหมือนแอป (PWA)

ไฟล์ `public/manifest.json` และ `public/sw.js` ถูกใส่ไว้ให้แล้ว เมื่อ deploy ขึ้นเว็บ
จริง (ที่มี HTTPS เช่น Vercel) ผู้ใช้จะสามารถ:

- **Android (Chrome):** เปิดเว็บ → เมนู 3 จุด → "เพิ่มลงในหน้าจอหลัก"
- **iPhone (Safari):** เปิดเว็บ → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"

ไอคอนที่ให้มา (`public/icon.svg`) เป็นไอคอนตัวอย่างเท่านั้น แนะนำให้เปลี่ยนเป็น
โลโก้จริงของสำนักวิทยบริการ/มหาวิทยาลัยก่อนใช้งานจริง

## ถ้าต้องการเป็นแอปเต็มรูปแบบใน App Store / Play Store

โปรเจกต์นี้เป็นเว็บแอป ยังไม่ใช่แอปมือถือแบบเนทีฟ หากต้องการขึ้น App Store /
Play Store จริง ๆ จำเป็นต้องพัฒนาต่อด้วยเฟรมเวิร์กอย่าง React Native หรือ Flutter
และสมัครบัญชีนักพัฒนา (Apple ~3,300 บาท/ปี, Google ~875 บาทครั้งเดียว) ซึ่งเป็นงาน
คนละขั้นตอนจากโปรเจกต์นี้

## รันดูในเครื่องตัวเอง (ถ้ามี Node.js ติดตั้งไว้)

```bash
npm install
npm run dev
```

แล้วเปิด http://localhost:5173

## สิ่งที่ยังเป็นข้อมูลจำลอง (ต้องต่อของจริงก่อนใช้งานจริง)

- สถานะโต๊ะ/ห้องว่าง-ไม่ว่าง อยู่ในหน่วยความจำเท่านั้น รีเฟรชหน้าเว็บแล้วจะรีเซ็ต
- ยังไม่มีระบบยืนยันตัวตนนิสิต (ควรเชื่อมกับระบบล็อกอินของมหาวิทยาลัย)
- ยังไม่มีฐานข้อมูลจริงเก็บประวัติการจอง
